# Security

Please don't open a public issue for a security problem. Report it privately on GitHub instead:
[Report a vulnerability](https://github.com/maxbenschop/maben-awake/security/advisories/new) (Security tab →
Report a vulnerability). Only the maintainer sees it, and you'll get a reply within a few days. More on how the
app limits what it can do: https://awake.maben.gg/security/.

Releases are signed with the Developer ID of team NJTYRVLSA8 and notarized by Apple. The app only installs an
update that passes the same checks.
